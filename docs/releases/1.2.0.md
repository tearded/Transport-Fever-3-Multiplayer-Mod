# TPF3-MP v1.2.0

## Install and play

On Windows, download **TPF3-MP.exe** and open it. The launcher downloads
the signed player package, installs the multiplayer mod for your Windows
account, and adds Start menu and optional desktop shortcuts. The EXE has
the project's icon. No ZIP extraction or administrator rights are needed.
The launcher checks for updates and keeps the mod and launcher together.

The portable ZIP remains available. Server operators have separate
`tpf3mp-server` archives; player downloads do not include a server.
The EXE has no Windows publisher signature. Downloaded packages are
verified using Ed25519 signatures and SHA-256 hashes.

## Changes since v0.1.0

- Dedicated **Join a friend** form with a player name and invite code;
  a multiplayer hub for hosting and browsing public rooms.
- New multiplayer worlds use the game's normal world-generation screens.
  Cancelled setup can be resumed, and players can leave and rejoin rooms.
- Host-only speed controls are reflected in the game's interface.
- Determinism fixes for vehicle routing and terminal selection, including
  the reported cargo-vehicle desync at industries.
- Station access permissions and synchronized terrain height tools.
- Road and track replay improvements, shared ballast and catenary, and
  room routing for supported mods' follow-up builds.
- Company-aware construction tools, stop ownership and names, and company
  markers on the map.
- Every company's lines appear on the map during a multiplayer game.
- Other players' road, track, station, stop and building previews appear in
  the game with terrain, then clear when the tool closes or the preview ends.
- Starting another world after leaving a room clears the previous world's
  company notes, avoiding a crash in the new world's first frame.
- Quick roadside-stop clicks are handled more reliably. Some rapid clicks
  can still be dropped; check that each stop appears before continuing.
- Better diagnostics: a shared log-session identifier and bounded,
  redacted hook, game and text crash-report uploads. The diagnostics
  setting controls these uploads; minidumps are not uploaded.
- A game rejoining a restored room now waits for the current world load,
  even if an older load finishes at the same step.

## Compatibility and remaining limits

Windows x64 with Steam game build **40408** is the supported game target.
Linux x64 and macOS arm64 packages are development builds pending real-game
platform acceptance.

This version uses protocol **17**, bridge **24**, and action schema **25**.
The relay, launcher, hook and mod must be upgraded together. Earlier builds
cannot share a room with this version. See
[the release process](../../AGENTS.md) and
[operations](../OPERATIONS.md#releases).

Some integrated channels remain disabled pending ordinary two-player
acceptance: subsidies, renaming/recolouring, waypoints, bridge/tunnel window
edits, junction tools, company perks and historic preservation. Tree/rock
removal remains opt-in. Terrain paint and asset brushes remain refused.
The line-viewer diagnostics do not repair invalid route data. See
[coverage and validation limits](../COVERAGE.md) for the current evidence.
